# str24 burn-down — what the 24-byte `str` switch has not reached yet.
#
# The switch (`STR_REPR.md`, stage 1) is committed but **off**: codegen emits it
# only when `AIPL_STR24` is set. Off, the compiler is byte-for-byte what it was
# and the suite is green; on, you get the new representation and the failures
# below. That gating is what lets the work land in main without a red suite.
#
# This is a ratchet: entries come out as the switch reaches them, and none go in
# to quiet an unrelated failure. When it is empty, stage 1 is done and the
# `aipl_*` half can be deleted.
#
#   cargo build && AIPL_STR24=1 cargo nextest run --no-fail-fast
#
# ---------------------------------------------------------------------------
# Why this is a list and not a set of `#[ignore]`s
#
# Two full runs under the switch failed 39 tests and 13 tests — with **no
# overlap**. The breakage is nondeterministic: a value that is 24 bytes to one
# code path and 8 to another corrupts whatever happens to sit next to it, and
# what that is depends on allocation order. So there is no stable set to ignore,
# and marking tests `#[ignore]` would have suppressed a moving target. Gating the
# switch off by default is the honest way to keep the suite green; this file is
# then a record of the work, not a suppression mechanism.
#
# ---------------------------------------------------------------------------
# Current state of the switched path (`AIPL_STR24=1`)
#
# Working end to end:
#     fn main() -> i64 { 7 }                 -> 7
#     print("short")                         -> short          (inline literal)
#     print("hello from a twenty-four ...")  -> hello ...      (static buffer)
#
# Not yet: anything calling a `str` builtin other than `print` — `len` on a
# literal returns garbage, because `active_sym` only remaps the entry points
# whose call sites have been converted and verified.
#
# ---------------------------------------------------------------------------
# Known-failing clusters, measured when literals and print were working. Counts
# are from that run; treat them as the shape of the work, not a current tally.
#
# 11  The FFI read path, **partly done**. The readers now take the callee's
#     `StrAbi` and read a wide `str` as the 24 bytes at the slot; that retired
#     five of the original sixteen (optional returns, array validation, the
#     grow-into-a-copy case, the doc example). What is left crashes rather than
#     mismatching, so the remaining cause is structural — composite *returns*
#     carrying a `str`, where the sret buffer and the field offsets have to agree
#     with a layout the callee computed under the wide representation.
