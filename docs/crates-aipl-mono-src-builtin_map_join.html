pub fn map_join<T: any, U: any>(self: T[], f: (T) -> U[], sep: U[] = [], final_sep: U[] = sep, only_sep: U[] = sep) -> U[]

self.map(f).join(sep=sep, final_sep=final_sep, only_sep=only_sep) — every f(x) flattened into one sequence with the separators between — computed in a single pass into a single buffer. The three separators are join's (sep between consecutive pieces, final_sep in the last gap, only_sep in the sole gap of a two-piece join), all defaulting to empty. Generic in both the element and what f maps it to; for a str-valued f the result is the string join. Callable as a method; a str receiver iterates its chars.
