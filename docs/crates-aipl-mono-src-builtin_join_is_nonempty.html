The AIPL implementation of the join_is_nonempty builtin. Monomorphization registers this function under the canonical name __builtin_join_is_nonempty (see AIPL_BUILTIN_SOURCES in lib.rs), so a user's xs.join_is_nonempty(sep=s) resolves through the ordinary generic machinery — the in-file name is only for this file's own tests, which read exactly like user code.

It is what xs.join(sep=s).is_nonempty() means, without building the join: join measures every piece, allocates the whole result and copies each piece in, and this asks only whether anything would be there. Written by the compiler's operation-fusion pass for that chain (see chain_fusions in aipl-mono); also callable directly.

pub fn join_is_nonempty<T: any>(self: T[][], sep: T[] = [], final_sep: T[] = sep, only_sep: T[] = sep) -> bool

True when self.join(sep=sep, final_sep=final_sep, only_sep=only_sep) has any element: some piece is non-empty, or — when every piece is empty — a separator that would be written between them is. The three separators are join's, all defaulting to empty, and which one applies is join's rule: only_sep in the sole gap of a two-piece join, final_sep in the last gap and sep in every other. Stops at the first non-empty piece; an empty self is false.
