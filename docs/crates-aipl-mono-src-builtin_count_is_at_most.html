pub fn count_is_at_most<T: any>(self: T[], x: T, limit: u64) -> bool

Fused form of count(x) <= limit — see count. Counts only as far as the answer needs, so a an early match decides it without walking the rest.

Written by the compiler's operation-fusion pass, which rewrites xs.count(x) <= n (and the mirrored n >= xs.count(x)) into this. Also callable directly.
