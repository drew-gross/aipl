The unused_binding lint: let x = value; (or mut x = value;) where nothing after it mentions x. The binding names a value nobody reads, which misleads the reader into looking for where it is used; the better spelling is to drop it, or the whole statement when the value is all it was for.

"Mentioned" is deliberately syntactic and generous, as it is for unused_imports: any mention of the name in the rest of the block counts, a set of it and a rebinding of it included. A missed dead binding costs one stale line, while a false hit costs a build that cannot be made to pass except by #[allow].

A name the parser made (__idx$3) was never written by the author, so it is not flagged. Every name an author wrote is, _ included: a value kept only for its effect is a statement, and a binding that must stay unused carries #[allow] like any other lint hit. Bindings a pattern makes (let P { a } = v;, for (let x : xs), parameters) are not lets here and are left alone.
