The AIPL implementation of the count_if_is_not_equal builtin. Registered under __builtin_count_if_is_not_equal (see aipl_syntax::aipl_builtins).

A fused comparison: count_if(pred) != limit without counting past the point the answer is settled. count_if itself always walks the whole collection; this stops as soon as the count passes limit, since no later element can bring it back, which is the entire reason the fusion pass exists. It is count_is_not_equal with a predicate in place of a value to compare against.

pub fn count_if_is_not_equal<T: any>(self: T[], pred: (T) -> bool, limit: u64) -> bool

Fused form of count_if(pred) != limit — see count_if. Counts only as far as the answer needs, so an early match decides it without walking the rest.

Written by the compiler's operation-fusion pass, which rewrites xs.count_if(p) != n (and the mirrored n != xs.count_if(p)) into this. Also callable directly.
