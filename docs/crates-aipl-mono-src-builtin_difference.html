The AIPL implementation of the difference builtin. The loader names this function by the canonical name __builtin_difference (see aipl_syntax::aipl_builtins), so a user's a.difference(b) resolves through the ordinary generic machinery — the in-file name difference is only for this file's own tests, which read exactly like user code.

difference fn 

pub fn difference<T: any>(self: #{T}, other: #{T}) -> #{T}

The elements of self that other does not hold, as a set. An empty other gives self back, and a self that other holds entirely gives the empty set.

Callable as a method (imported.difference(used)). Both operands are sets of any order; the result is always unordered, because it is built by dropping elements from a sequence. Ask for an order when you want one — a.to_array().filter(|x| !b.has(x)).to_set() with the binding annotated #<{T} — so the ordering is written down rather than inferred.

See intersection for the elements both sets hold, and union for those of either.
