The extend_loop_map_join lint:

mut out = [];
for (let x : xs) {
    set out.extend(f(x));
}

— an array seeded empty and filled by a loop that does nothing but extend it with something derived from each element. That is xs.map(|x| f(x)).join(): one expression that says the array is the pieces joined, rather than statements the reader has to run in their head. It is push_loop_pipeline's twin, for a loop that adds an array per element rather than one element, and recognises the shape the same way (see accumulation.aipl); a guard around the extension is a filter first.

The one thing this cannot check is what each extension is: extend also takes an optional, which adds its payload if there is one, and join does not. A loop that extends with optionals is the lint's blind spot, and #[allow] is the answer there. Nor can it check that xs is an array, for the reasons push_loop_pipeline gives.

The hit points at the seed.
