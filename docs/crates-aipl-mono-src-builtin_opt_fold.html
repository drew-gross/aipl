The AIPL implementation of the opt_fold builtin: fold with a fallible combiner. The loader names this function by the canonical name __builtin_opt_fold (see aipl_syntax::aipl_builtins), so a user's xs.opt_fold(init, f) specializes through the ordinary generic / higher-order machinery.

From the left, f is not called again once a step has failed, so the fold's work stops at the first none — but the walk itself continues (AIPL has no break). That keeps the plain for, whose element access streams a str receiver through the char cursor; an index-driven while that really exits early reads self[i] per element, which costs far more than the leftover if (ok) ticks. From the right the walk is index-driven anyway and does exit early. The accumulator stays a plain A — the ok flag, not an A? threaded through the loop, carries the failure. A mut binding of an optional (a composite) reassigned from inside a loop body is currently miscompiled: the body's scope releases the new value's heap components while the binding still points at them, so a str/array/boxed accumulator would corrupt. A plain A binding goes through the slot-owned-reference model instead, which is correct across scopes.

opt_fold fn 

pub fn opt_fold<T: any, A: any>(self: T[], init: A, f: (A, T) -> A?, direction: Direction = Left) -> A?

Combine the elements one at a time with a fallible combiner, into an accumulator that starts as init: f returns A?, and the first none ends the fold with none — the remaining elements are never visited. All-some folds to some(result), exactly as fold would; an empty array folds to some(init).

Since the combiner's body may use ?, a fold that can fail reads as one expression: s.opt_fold(0, |acc, c| some(acc * 10 + c.to_digit()?)).

  • self: T[]
  • init: A

    The accumulator the first element met is combined with.

  • f: (A, T) -> A?

    Combines the accumulator and an element into the next accumulator, or none to end the fold.

  • direction: Direction = Left

    Which end the walk starts at: Left (the default) at the first element, Right at the last.
