The map_find_if_some lint:

xs.map(f).find_if(is_some)

— the first element f has an answer for, written as a chain that hands back the answer wrapped twice. xs.find_map(f) says it in one word, and hands back the answer once: the chain's result is a U?? whose outer layer every caller then peels (.value_or(none)), while find_map returns the U? that was wanted.

The predicate has to be is_some — the name; a lambda forwarding to it is eta_lambda's to turn into the name — since that is what makes the chain a find_map rather than a search over mapped values (map_find_if's shape, which the fusion pass takes care of). map, find_if and is_some are the precondition, since the shape is theirs, and a file that has not imported one of them is not writing it; find_map only decides whether the advice names an import too.

The hit points at the whole chain.
