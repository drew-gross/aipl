The AIPL implementation of the first builtin. Monomorphization registers this under the canonical name __builtin_first (see AIPL_BUILTIN_SOURCES in lib.rs), so a user's xs.first() resolves through the ordinary generic machinery.

Indexing already yields an optional — some(elem) in bounds, none out of bounds — so the empty case needs no special handling: [][0] is none.
