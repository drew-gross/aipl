The AIPL implementation of the all builtin. Monomorphization registers this function under the canonical name __builtin_all (see AIPL_BUILTIN_SOURCES in lib.rs), so a user's xs.all(pred) specializes through the ordinary generic / higher-order machinery — the in-file name all is only for this file's own tests, which read exactly like user code.

all fn 

pub fn all<T: any>(self: T[], pred: (T) -> bool) -> bool

True when every element satisfies pred, short-circuiting at the first element that fails it; an empty array is vacuously true. Generic over the element type and callable as a method: xs.all(pred).
