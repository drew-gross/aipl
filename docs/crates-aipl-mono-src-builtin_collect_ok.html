The AIPL implementation of the collect_ok builtin. The loader names this function by the canonical name __builtin_collect_ok (see aipl_syntax::aipl_builtins), so a user's xs.collect_ok() resolves through the ordinary generic machinery.

It is the other half of a map whose function may decline: xs$read() is a T?[], one slot per element, and this keeps the answers. The elements stay in order, and the result is no longer than the receiver. A loop that pushes only when if (let some(v) = f(x)) matches is this, written the long way.
