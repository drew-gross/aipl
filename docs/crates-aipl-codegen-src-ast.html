Ast variant 

variant Ast

The one type every build in grammar_aipl.aipl returns, whatever the production is about — Build<A> pins a single A for a whole grammar, so a grammar describing a language rather than one expression type carries the seam here. Each case is a node kind the lowering produces.

Two cases are not node kinds but the intermediate a production hands its parent. Tys is the *list* a production whose whole content is a comma-separated run of types lowers to, and the case it lands in is what tells ty's alternatives apart — (A, B) and A reach ty as different Ast cases, so nothing has to count tokens to know which matched. Payload is a constructor pattern's slot list and whether it was written .., which is the pair Pat's Ctor needs and no node of its own.
