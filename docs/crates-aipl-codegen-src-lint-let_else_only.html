The let_else_only lint:

let [binder] = bindings else {
    return none;
};

— an array taken apart for its one element, with none as the answer when it holds none or several. That is let binder = bindings.only()?;, which says the same without the block. (A hand-written if (let [binder] = bindings) { rest } else { return none; } lowers to the same tree and is the same program.)

It has to be the function's tail (see tail_matches), where the ? and the block's return both leave the function with the same answer, and the else has to be exactly return none;: a block that does anything first, or returns something else, is a different program. The pattern has to be one plain name, or _, which asks only whether there is one element and is then written as the statement bindings.only()?;. A second element, a literal, or a trailing .. (which allows more than one) is a different question.

The hit points at the none after return, on a line the formatter keeps in place, so #[allow] squelches it.
