The AIPL implementation of the remove_index builtin. The loader names this function by the canonical name __builtin_remove_index, so a user's xs.remove_index(i) resolves through the ordinary generic machinery.

It is the array without one element, by position: drop_first and drop_last remove an end, drop_n a prefix, and this the element between. No lint flags the longhand [..xs[..i], ..xs[(i + 1)..]]: it is one shape among the many ways to build an array from slices, and the rewrite would not read better in each of them.
