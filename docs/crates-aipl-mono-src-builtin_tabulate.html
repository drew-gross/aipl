The AIPL implementation of the tabulate builtin. The loader names this function by the canonical name __builtin_tabulate (see aipl_syntax::builtin), so a user's rows.tabulate(headers) specializes through the ordinary generic machinery — the in-file name is only for this file's own tests, which read exactly like user code.

No lint steers the longhand here: a hand-drawn table is built from so many different pieces (separators, padding, borders) that no shape could be advised precisely, and a mis-advised lint is worse than ntwo.

tabulate fn 

pub fn tabulate(self: str[][], headers: str[], right_aligned: bool[] = []) -> str[]

rows drawn as a table, as lines: a rule above, headers and a heavier rule under them, the rows, and a rule below. Each column is as wide as its widest cell, padded on the right, or on the left for a column right_aligned marks (a column it does not reach is on the left). Callable as a method.
