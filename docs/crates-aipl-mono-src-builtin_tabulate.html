The AIPL implementation of the tabulate builtin. The loader names this function by the canonical name __builtin_tabulate (see aipl_syntax::builtin), so a user's rows.tabulate(columns) specializes through the ordinary generic machinery — the in-file name is only for this file's own tests, which read exactly like user code.

No lint steers the longhand here: a hand-drawn table is built from so many different pieces (separators, padding, borders) that no shape could be advised precisely, and a mis-advised lint is worse than ntwo.

struct Column

A column of a table: what its header says, and the side its cells are padded on: Right leaves the text on the left, and Left puts it on the right, as for numbers.

tabulate fn 

pub fn tabulate(self: str[][], columns: Column[]) -> str[]

rows drawn as a table, as lines: a rule above, the headers of columns and a heavier rule under them, the rows, and a rule below. Each column is as wide as its widest cell, its header included, and its cells are on the side its Column says. A row with fewer cells than there are columns has blanks for the rest, and one with more is cut off. Callable as a method.
