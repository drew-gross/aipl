Lowering the destructuring forms, after the lints have read them.

let T { x, y } = v;, let (a, b) = v;, let Case(a) = v;, the same in a for header, and a pattern in a parameter are kept as written when a file is parsed (LetPattern, ForPattern, Param::pattern). The lints that run next see what the author wrote, not the temporaries the lowering would bind, so none of them has to recognise a name the compiler made. This is the pass that does the binding: each form becomes the lets and one-arm matches that bind its names off a temporary, and nothing past it knows the surface form existed.

Spans and the temporaries' names come from the value or iterable the pattern takes apart, as they always have, so the tree this produces is the one the parser used to produce directly.

bind_arm fn 

fn bind_arm(case_name: str, names: str[], tmp: str, span: Span, rest: Expr) -> Expr

let a = match (<tmp>) { Case(a, _) => a }; let b = match (<tmp>) { Case(_, b) => b }; rest, innermost last — what let Case(a, b) = value; rest binds, one match per name. The scrutinee is a value that can only be Case, which is what makes each match exhaustive with the one arm; any other value is refused by that check. A match for each name, rather than one around the rest of the block, keeps rest out of an arm: a block that is an expression may not assign to a binding from outside it.

destructure_struct fn 

fn destructure_struct(struct_name: str, fields: str[], names: str[], value: Expr, span: Span, acc: Expr, mutable: bool, tmp: str) -> Expr

let T { a, b } = value; rest and its mut twin, as nested bindings. The scrutinee stays an immutable let either way — it is read once per field and never written through — and carries the pattern's type as its annotation, which is what makes the type name mean something rather than decorate the line. The __spat$ prefix is aipl_syntax::DESTRUCTURE_BASE_PREFIX, which is how the checker knows to report a mismatch as the destructuring it was.
