The let_else_as_case lint:

let Field(base, field) = x else {
    return none;
};

— a variant value taken apart, with none as the answer when it is another case. That is let Field(base, field) = x.as_case(Field)?;, which says the same without the block. (A hand-written if (let K(..) = x) { rest } else { return none; } lowers to the same tree and is the same program.)

It has to be the function's tail (see tail_matches), where the ? and the block's return both leave the function with the same answer, and the else has to be exactly return none;: a block that does anything first, or returns something else, is a different program. Only a variant case's constructor pattern is advised — an optional's some(v) has no as_case, and an array or tuple pattern is not a case.

A case with no payload to bind has no pattern of its own to write in a let (a bare name would be a binding), so it is asked of the value alone: x.as_case(Empty)?;.

The hit points at the return none; line, a short statement the formatter keeps in place, so #[allow] squelches it.
