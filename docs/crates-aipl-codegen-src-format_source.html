format_source fn 

pub fn format_source(src: str, width: u64) -> str!FmtError

Format AIPL source to the canonical style, at width. The output always ends in exactly one newline (an empty program formats to just that). The input's trailing --- section --- blocks are preserved byte-for-byte — they follow that newline, and whatever they end with is theirs; trailing whitespace in the source portion is removed (the language rejects it, so fixing it can't change an accepted program's meaning).

verify_same_tokens fn 

fn verify_same_tokens(input: str, output: str) -> ()!FmtError

Refuse unless output holds exactly input's tokens and comments. Imports may be reordered, so both are compared as sorted multisets rather than in position. A token is compared by its *value* — to_str of its kind, which carries a literal's decoded value and a name's spelling — so the formatter's value-preserving whitespace edits inside a """ block are not flagged, while any change to a literal's value is.

Trailing commas are normalized by design (dropped when a list renders flat, added when it breaks), so commas don't take part. A variant's *leading* | is the same normalization at the other end (dropped flat, added when the cases break), so | sits out too — which also excludes the | between match-pattern alternatives, the price of comparing multisets rather than positions.
