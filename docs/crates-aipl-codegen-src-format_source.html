fmt_prepare fn 

pub fn fmt_prepare(src: str) -> FmtInput

The first half of format_source: src split into the code to format (trailing whitespace already stripped) and its trailing --- section --- blocks, which are copied to the output verbatim rather than laid out.

The caller parses cleaned before handing it to fmt_layout.

fmt_layout fn 

pub fn fmt_layout(cleaned: str, width: u64) -> str!FmtError

The second half of format_source: lay cleaned out at width, then normalize to exactly one trailing newline — including for an empty program, which formats to just that. The printer only keeps a trailing newline when the layout happens to end with one, so the guarantee is made here rather than there.

The caller verifies the result carries the same tokens as cleaned, then appends the sections fmt_prepare set aside.
