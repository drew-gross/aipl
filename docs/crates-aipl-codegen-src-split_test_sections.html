pub fn split_test_sections(src: str) -> (str, str)

Splits src at the first --- name --- test-section marker line into (main, sections): the source before the marker, and the marker plus everything after it. When there is no marker, sections is empty and main is all of src. The counterpart of strip_test_sections, which returns only the main half. (parse_test_section_header classifies each line.)
