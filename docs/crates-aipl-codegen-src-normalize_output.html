The cases harness's captured-output normalizer: the test harness calls this through the embedding FFI (see aipl::codegen::normalize_output) to compare a child program's stdout/stderr against the expected sections, and aipl check exercises it via the .test block below. Collapsing CRLF to LF matters on Windows, where libc text-mode stdout rewrites the runtime's \n to \r\n.

pub fn normalize_output(self: str) -> str

Normalizes captured program output for the cases harness: collapses CRLF line endings to LF, then strips the trailing run of \n/\r. A lone interior CR is left untouched.
