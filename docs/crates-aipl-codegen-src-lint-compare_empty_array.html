The compare_empty_array lint: xs == [] and xs != [] — emptiness asked by comparing with an empty array. xs.is_empty() and xs.is_nonempty() ask it directly, and build no array to compare against.

It is the sibling of is_empty_longhand and len_gt_zero, which send xs.len() == 0 and xs.len() > 0 to the same places. Either side may be the literal. A comparison of two empty literals is not a question about a value and is left alone, and so is any other operator, and an == or != that the file binds to a function of its own.

The receiver is written out where it has a spelling, and the advice says "the receiver" where it has none.

The hit points at the comparison, which begins on the line the #[allow] would be written on.
