The zip_with_pair_zip lint:

xs.zip_with(ys, |a, b| { (a, b) })

— a zip_with whose function does nothing but build the pair of its two arguments, in the order it got them. That is xs.zip(ys), which says the result is the pairs instead of a function the reader has to read to find out that it combines nothing.

Exactly this shape: a function with two parameters and a body that is the tuple of those parameters, first then second. A swapped pair is a different array, and a body that computes anything is a real combining function, which zip_with is for.

The hit points at the function, which begins on the line the #[allow] would be written on.
