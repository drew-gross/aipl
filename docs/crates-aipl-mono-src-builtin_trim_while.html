pub fn trim_while(self: str, pred: (char) -> bool) -> str

Drops the leading run of characters satisfying pred, returning the remainder (everything from the first character that fails pred onward); the whole string when pred fails immediately, and "" when every character satisfies it. Callable as a method: s.trim_while(pred).
