Where the names in a pattern are written.

A pattern is kept as text (Pat), which is all the compiler needs, so the places its names stand in the source are read off the pattern's tokens as the parser lowers it. A language server needs them: the case a pattern names, the names it binds and the fields a struct pattern reads are each something to jump to or from.

written_names fn 

pub fn written_names(tokens: Span[], src: str, bare_is_case: bool) -> WrittenNames

The names tokens spell, in a pattern written in src. tokens are the pattern's token spans, nothing before or after it.

A name followed by ( or written after a . is a case, and one followed by { opens a struct pattern, whose own name is a type. Any other name is a binder unless it spells a case (none, or capitalised) — and bare_is_case says the pattern's top level is a case position: at the head of a match arm a bare name is a nullary case, where in a let it binds.
