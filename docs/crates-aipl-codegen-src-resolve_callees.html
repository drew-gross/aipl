Which builtin each call is to, for the lints.

A call names a function as the file spells it, and a file may import a builtin under any name (import { len as length } from builtins;), so what a call is to is a fact about the file's imports and not about the text. This fills in the callee of every call to a name the file imported from a builtins library, leaving none for a call to anything else: a function of the file's own, a constructor, or a local that holds a function and so hides the import.

Only the lints read the result. The program the rest of the compiler gets is the one before it.

The result is typed as what it is: a ResolvedProgram has no Unresolved callee anywhere in it, so the lints, which take one, cannot be handed a program that skipped this pass.
