link fn pub 

pub fn link<K: variant, A: any>(g: Grammar<K, A>) -> Grammar<K, A>!ParseError

g with every rule reference resolved: each Named(name) rewritten to the NamedIdx(index) of the production it names, so the driver resolves a reference by indexing rather than by comparing strings. Fails when a reference names no production, or when two productions share a name.

Idempotent — a NamedIdx passes through — so a grammar may be linked once and reused, or handed to parse unlinked and linked per call.
