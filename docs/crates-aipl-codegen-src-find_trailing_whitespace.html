line_end_span fn 

fn line_end_span(prev: char, prev2: char, boundary: u64, ws_start: u64, line_start: u64) -> Span?

The span of a line's trailing space/tab run, given the bytes around its ending, or none if the line has none. boundary is the index of the line-ending '\n' (or the input length, at EOF); prev/prev2 are the two bytes before it; ws_start is where the current run of spaces/tabs began; line_start is the line's first byte. A single '\r' right before the boundary is part of a CRLF (or lone-CR) ending, so the last content byte is the one before it.

find_trailing_whitespace fn pub 

pub fn find_trailing_whitespace(src: str) -> Span?

The byte Span of the first line's trailing space/tab run in src as some(span), or none if no line has trailing whitespace. A single CR before a LF is part of a CRLF line ending, not content. The locator for the parser's trailing-whitespace check.
