pub fn int_fits(v: i64, name: str) -> bool

Whether the integer value v (an i64 literal) is representable in the integer type named name ("i8".."u64"). u64 accepts any non-negative value — a literal can't exceed i64::MAX, which fits u64. Any non-integer name is false. This is the compiler's flexible-literal range check (a bare literal flowing into a narrow-int context), dogfooded through the FFI.
