pub fn int_fits(v: i64, name: str) -> bool

Whether the integer value v is representable in the integer type named name. This is the compiler's flexible-literal range check (a bare literal flowing into a narrow-int context), dogfooded through the FFI.

  • v: i64

    An i64 literal's value.

  • name: str

    An integer type's name, "i8".."u64"; any other name gives false. u64 accepts any non-negative value — a literal can't exceed i64::MAX, which fits u64.
