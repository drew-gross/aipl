clear_screen fn 

pub fn clear_screen() !prints

Clears the terminal and puts the cursor at the start of its second line: it prints the control sequence that clears and homes, and print ends what it writes with a newline. Output that is not a terminal receives the sequence as text, so a program that is piped should not call it. Carries !prints, so a shim prints can stand in for the terminal.

fn clear_sequence() -> str

What a terminal is sent to clear its screen: the control sequence "erase the whole display" (ESC [ 2 J), then "move the cursor to the top left" (ESC [ H).
