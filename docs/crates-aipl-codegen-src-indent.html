The content half of the formatter's raw-block re-layout (see reindent_block): indents a block of text — the lines between a raw-string / template atom's delimiters, with no """ / ``` framing — by a chosen column. Split out so reindent_block deals only with the delimiters. Assumes the input is already fully dedented (its common indent is 0): it adds target spaces, it does not rebase an existing indent — reindent_block dedents first (via dedent).

pub fn indent(self: str, target: u64) -> str

Indents every non-blank line of self by target spaces, keeping each line's own relative indentation; blank (empty or all-whitespace) lines are emitted empty. Assumes self is already fully dedented — it adds indentation, it does not rebase an existing common indent to target. The inverse of dedent; reindent_block dedents the raw-block content before calling this.
