The match_bool_is_case lint:

match (shape) {
    Circle(..) => true,
    Square(..) => false,
}

— a variant value turned into whether it is one case. That is shape.is_case(Circle), which says so without the other arms and stays right when the variant gains a case.

The shape is exact: every arm's body is a true or false literal, exactly one of them is true, and its pattern is a variant case's constructor. some, none, ok and err are optionals and results rather than cases of a variant the program declares, and a bare lowercase name binds rather than naming a case, so neither is advised. A second true arm (A | B => true) is two cases, which is_case does not ask about.

The hit points at the true arm, a short line the formatter keeps in place.
