Filling in each expression's source: the text its span covers.

A lint that advises a rewrite wants to quote the code it saw (s[3..], not <receiver>[<start>..]), and it is given a program, not the file. So the parser records the text on the node, once, here — the only place that holds both.

A slice of a large source shares its buffer rather than copying it, so every node carrying its text costs a pointer and a length, however long the text is.
