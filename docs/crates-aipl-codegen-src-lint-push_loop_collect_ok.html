The push_loop_collect_ok lint:

mut out = [];
for (let x : xs) {
    if (let some(v) = f(x)) {
        set out.push(g(v));
    };
}

— an array seeded empty and filled by a loop that asks something of each element and pushes only the answers that exist. That is xs.map(|x| f(x)).collect_ok() (no map first when the loop variable is the optional itself), with a .map(|v| g(v)) after it when what is pushed is more than the bound name: one expression that says the array is the answers, rather than a loop the reader has to run to find out that nothing else happens to out.

It is the optional-guard sibling of push_loop_pipeline, which reads a boolean guard and so a filter; the two are disjoint by the kind of if. The shape is held to the same discipline: the loop body is the one if let around the one push, it has no else, the pattern is a plain some(v), and neither the scrutinee nor the pushed element may mention out (see is_liftable). An indexed loop is left alone, since map has no index to pass, and a str or set receiver is the blind spot push_loop_pipeline documents: #[allow] is the answer there.

The hit points at the seed, like push_loop_pipeline.
