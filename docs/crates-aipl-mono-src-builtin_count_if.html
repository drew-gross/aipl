count_if fn 

pub fn count_if<T: any>(self: T[], pred: (T) -> bool) -> u64

Counts how many elements of self satisfy pred, examining every element. Generic over the element type and callable as a method: xs.count_if(pred). A str receiver iterates its chars, since str and char[] share a representation.

See count for the equal-to-a-value form, and count_while for the leading-run form that stops at the first element failing pred.
