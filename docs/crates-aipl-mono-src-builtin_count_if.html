The AIPL implementation of the count_if builtin. Monomorphization registers this function under the canonical name __builtin_count_if (see AIPL_BUILTIN_SOURCES in lib.rs), so a user's xs.count_if(pred) resolves through the ordinary generic / higher-order machinery — the in-file name count_if is only for this file's own tests, which read exactly like user code.

It completes the trio: count counts elements equal to a value, count_while counts a leading run matching a predicate, and this counts every element matching a predicate, anywhere. Unsigned, like len: a count is never negative.

count_if fn 

pub fn count_if<T: any>(self: T[], pred: (T) -> bool) -> u64

Counts how many elements of self satisfy pred, examining every element. A str receiver iterates its chars, since str and char[] share a representation.

See count for the equal-to-a-value form, and count_while for the leading-run form that stops at the first element failing pred.
