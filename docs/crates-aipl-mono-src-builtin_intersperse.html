The AIPL implementation of the intersperse builtin. Monomorphization registers this function under the canonical name __builtin_intersperse (see AIPL_BUILTIN_SOURCES in lib.rs), so a user's xs.intersperse(sep) specializes through the ordinary generic machinery.

The array counterpart of join: join is this followed by concatenation, which only str can do — every element type can be interleaved, so that is where the generic version stops. Doc[] is the motivating case, where the result is handed to a Concat.

pub fn intersperse<T: any>(self: T[], sep: T) -> T[]

Insert sep between consecutive elements, returning a new array: [a, b, c].intersperse(s) is [a, s, b, s, c]. An empty or single-element array comes back unchanged — a separator only ever appears between two elements, never leading or trailing.

For str[] prefer join, which does this and concatenates the result in one step.
