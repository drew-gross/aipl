The match_case_as_case lint:

match (shape) {
    Circle(..) => some(shape),
    _ => none,
}

— a variant value handed back when it is one case and none otherwise. That is shape.as_case(Circle), which says so without the second arm, and whose result is typed as the one case it holds.

The shape is exact: two arms, the first a variant case's constructor pattern whose body is some(x) of the very value matched, and the second the catch-all giving none. What the first arm binds is no matter, since the body does not read it. An arm that returns anything but the scrutinee — a payload, a rebuilt value — is a different program, and as_case is not its spelling.

The hit points at the _ => none arm, a short line the formatter keeps in place, so #[allow] squelches it.
