pub fn caret_block(source: str, span: Span, filename: str) -> str

The error renderer's caret-block formatter: the compiler calls this through the FFI (see install_parser_hooks) when rendering an error with a span. Given source and span (a half-open byte range [start, end)), it returns the rustc-style location + underline block (no leading error:/note: label):
