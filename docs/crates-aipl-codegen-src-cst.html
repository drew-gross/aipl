Cst variant 

variant Cst

An interior node is CTree(prod, kids); a CGroup is the bracket pair a NestedIn matched, holding its opening kids, the kids between the brackets, and its closing kids as three runs.

A group is *transparent*: it is not a production, it lowers to nothing of its own, and nodes and own_tokens splice straight through it — so converting a Then([Lit("("), x, Lit(")")]) into a NestedIn leaves every build function reading exactly the children it read before. The only pass that sees a group is the formatter, which is the pass that needs to know where the brackets are.

is_tree fn 

pub fn is_tree(self: Cst) -> bool

Whether self is an interior node. The parser's lowering pass hands a production's build only the values of its *interior* children — a leaf has no lowered value, and its text is reachable from the node's own span — so this is the filter that decides what counts as a child.

leaves fn 

pub fn leaves(self: Cst) -> Span[]

Every leaf span under self, in source order — token leaves and trivia alike. The whole losslessness property is stated in terms of this list: the spans are contiguous and cover the parsed source, so text is just "slice each one and join".

text fn 

pub fn text(self: Cst, src: str) -> str

The source text self covers, reconstructed from its leaf spans. For a whole parse this equals the input exactly; that identity is the cheapest regression test there is for the driver's trivia handling, so the .test blocks assert it directly.

token_leaves fn 

pub fn token_leaves(self: Cst) -> Span[]

Every *token* leaf span under self, in source order — leaves with the trivia dropped. The two are the lossless/meaningful pair: leaves keeps the comments and whitespace because reconstructing the source needs them, and this one drops them because a lowering function reading a token's spelling does not want the blank line in front of it.

token_text fn 

pub fn token_text(self: Cst, src: str) -> str

The text of the tokens under self, trivia dropped and nothing inserted between them — what a production's build reads a matched token's spelling from. Written for the single-token node that is the usual case; over a wider node the tokens run together (( a b ) reads back as (ab)), which is why text and not this one is what reconstructs source.

span fn 

pub fn span(self: Cst) -> Span

The span self covers: its first leaf's start through its last leaf's end. A node with no leaves at all — an interior node for a production that matched empty input, which Maybe and a zero-minimum Many can both produce — has no extent, and reports the empty 0..0.

nodes fn 

pub fn nodes(self: Cst) -> Cst[]

The interior children of self — its kids with the leaves dropped. This is the child list a production's build is lowered against, so its order and length are part of the contract between a grammar and its lowering functions: one entry per Named reference the rule matched, in the order it matched them.

own_tokens fn 

pub fn own_tokens(self: Cst) -> Span[]

The token leaves self matched *directly* — one level down, not recursed into. The mirror of nodes: that one is a node's direct branches, this its direct leaves, and between them they are everything the node itself matched.

This is what a lowering function reads an operator or a keyword from. A Climb node's two operands arrive as interior children and the operator between them is a direct leaf, so own_token_text is the operator and nothing else — where token_text would hand back the whole expression's tokens run together. Trivia is dropped here as it is there.

own_token_text fn 

pub fn own_token_text(self: Cst, src: str) -> str

The source text of self's direct token leaves, run together with nothing between them — the operator of a binary node, the keyword that opened a form.

show fn 

pub fn show(self: Cst, src: str, names: str[]) -> str

self rendered as an S-expression against the grammar's production names (prod_names), for tests and for reading a tree by eye: a leaf as its source text, a trivia leaf prefixed with ~, an interior node as (name kid kid ...). A production index with no name in names renders as ? rather than failing — this is a debug rendering, not a checked one.

flat_kids fn 

fn flat_kids(self: Cst) -> Cst[]

The direct kids of self with every group spliced in place — the one function that makes a group transparent, and what nodes and own_tokens are both written against. A group's three runs concatenate in source order, and a group nested directly inside another flattens with it.

splice fn 

fn splice(self: Cst) -> Cst[]

One kid as the kids it stands for: a group as its contents, anything else as itself.
