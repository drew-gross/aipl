The AIPL implementation of the collect_arms builtin. The loader names this function by the canonical name __builtin_collect_arms (see aipl_syntax::aipl_builtins), so a user's xs.collect_arms(Circle) resolves through the ordinary generic machinery — the in-file name collect_arms is only for this file's own tests, which read exactly like user code.

What the body returns is a T[], but a call in a user's file is typed more precisely than that: the checker reads the case off the constructor reference passed as arm and types the result as an array of T without every other case (see refine_collected_arms in aipl-mono) — the array of that case's own type, so shapes.collect_arms(Circle) is a Circle[]. The elements are the same values either way — the refinement costs nothing at run time — but a match on one needs only the arm that was collected and refuses any other, and for (let Circle(r) : ..) takes its payload with no match at all.

There is no lint steering callers here: the longhand, xs.filter(|x| x.case_of() == Circle), is a different program (its elements are still any case of T), not a worse spelling of this one.

pub fn collect_arms<T: variant>(self: T[], arm: Case<T>) -> T[]

The elements of self that are the case arm, in order. arm is a constructor name, payload-carrying or not: shapes.collect_arms(Circle). An array with none of that case gives an empty one.

See filter for keeping elements by an arbitrary predicate, and case_of for reading which case a single value is.
