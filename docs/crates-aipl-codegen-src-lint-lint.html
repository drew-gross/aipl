The lints, run over a parsed file.

squelch is applied to what these return: it drops the hits an #[allow] marker covers and says how to keep the rest. A lint is added by giving it its own file and a line in lint; the hits come back in the order the lints are listed.

Public

lint fn 

pub fn lint(program: Program) -> LintHit[]

Every hit the ported lints find in program.

A lint is either a function of the whole program or of one function. The program's functions are listed once, and each function lint is run over them: every body that is code. One that also needs the file's imports takes the program's items beside the function.

lint_str fn 

pub fn lint_str(src: str) -> str[]!ParseFailure

The messages every lint reports for the program src parses to, which is how a lint's own tests read what it says: they run all the lints, so a snippet must be one no other lint objects to.
