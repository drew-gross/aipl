pub fn lint(program: Program) -> LintHit[]

Every hit the ported lints find in program.

A lint is either a function of the whole program or of one function. The program's functions are listed once, and each function lint is run over them: every body that is code. One that also needs the file's imports takes the program's items beside the function.
