The lints that have moved to AIPL, run over a parsed file.

aipl_syntax::lint::check is the driver: it runs the lints still written in Rust, adds what this returns, and squelches the hits an #[allow] marker covers. A lint moves here by getting its own file and a line in lint; the hits come back in the order the lints are listed.
