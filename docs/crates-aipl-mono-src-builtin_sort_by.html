pub fn sort_by<T: any>(self: T[], less: (T, T) -> bool) -> T[]

Sorts by a caller-supplied less predicate: less(a, b) is true when a must come before b. Stable — elements neither of which precedes the other keep their input order. Generic over the element type and callable as a method: xs.sort_by(|a, b| a.key < b.key).
