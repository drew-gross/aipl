The AIPL implementation of the words builtin. The loader names this function by the canonical name __builtin_words (see aipl_syntax::aipl_builtins), so a user's line.words() resolves through the ordinary machinery — the in-file name is only for this file's own tests, which read exactly like user code.

No lint points s.trim().split(" ").filter(is_nonempty) here: it is one site so far, and it splits on spaces only, so the rewrite would also change what a tab does.

pub fn words(self: str) -> str[]

The words of self: the runs of characters between ASCII whitespace (space, tab, newline, carriage return, vertical tab and form feed), in order. Leading, trailing and repeated whitespace separate words but never make an empty one, so a string with no words, empty or all whitespace, gives [].

See split to cut at one exact separator and keep the empty pieces between.
