The char_set_literal lint: #{'a', 'b', 'c'} — a set of char literals spelled out one quoted element at a time. "abc".to_set() is the same set, written as the thing it describes: the characters, in a row, with nothing between them.

It reads better at every size and it costs nothing. to_set on a string literal is folded by codegen into the four immediate stores that are a #{char}'s whole representation (see the Callee::ToSet arm in aipl-codegen), which is exactly what the set literal compiles to — the two spellings emit byte-identical IR, so the shorter one is free.

Three elements or more: two is where the spellings are a tie — #{'a', 'b'} and "ab".to_set() are the same width, and the literal keeps each element visibly a char. From three on, the quotes and commas outweigh the characters they separate, and the sets that matter in practice (a character class, a set of punctuation, the digits) are far past three, where the literal form is almost unreadable.

Only the unordered #{..}. An ordered literal is not interchangeable: to_set leaves its order to the use site, so #<{'z', 'a', 'm'} where nothing pins an order — rendered straight into a template, say — would become the unordered set and stop sorting. A lint may not advise a rewrite that changes what the program does.

Only a literal written on one line, which is what keeps every hit squelchable. #[allow] is line-scoped, and the formatter breaks a set literal too wide for one line into one element per line — then relocates a trailing marker from inside the braces onto the statement's closing };, a line the span does not start on. A literal it keeps on one line carries the marker at the end of that line, where it does squelch.

Only elements with a spelling in a string. The escapes are the ones AIPL's own string rule accepts (\n, \t, \r, \\, \"); anything else non-printable is left alone rather than guessed at, since advice that does not lex is worse than no advice.

The advice puts the string in backticks, not the quotes the other lints use: the advice is a string literal, and ""abc".to_set()" reads as neither. The file's to_set is named if the file has none, which is what makes the advice followable.
