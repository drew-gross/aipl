Sexp variant 

variant Sexp

The AST an S-expression lowers to: a bare atom, or a list of them. Recursive through an array, so a Sexp is a refcounted heap block — the shape a build function value had to be proven able to return.

  • Atom(str)
  • List(Sexp[])

render_sexp fn 

pub fn render_sexp(self: Sexp) -> str

self printed back as S-expression source, in the one canonical spelling: atoms as themselves, a list as its elements joined by single spaces.

Round-trips with parse_sexp — parse_sexp(render_sexp(v)) == v for every v — which is what makes the pair a usable end-to-end check of the library.

depth fn 

fn depth(self: Sexp) -> u64

How deeply self nests: an atom is 0, a list one more than its deepest element. The deep-nesting assertion's whole content — a parse that silently stopped early would show up here as a shallower tree.
