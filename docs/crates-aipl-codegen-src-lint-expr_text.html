The source text of an expression, written from its tree: what a lint's advice quotes when it says "write xs.is_empty()" about code it read as len(xs) == 0.

It renders the forms a receiver or an interpolated value is made of — names, literals, field paths, calls, operators, indexing, slices, array and tuple literals — and says none for the rest (a lambda, a match, a block), which advice then describes instead of quoting. What it writes parses back to the tree it was written from: an operand that is itself an operator use is parenthesized, so (a + b).len() is not a + b.len().

The span of a node is not used: a call's span stops before its closing paren, so the source text of one is no spelling of it.
