The source text of an expression, written from its tree: what a lint's advice quotes when it says "write xs.is_empty()" about code it read as len(xs) == 0.

It writes every form of the language: what comes back parses to the tree it was written from. An operand that is itself an operator use is parenthesized, so (a + b).len() is not a + b.len(), and a block is written on one line, its statements between braces. A call the parser made of another form (__builtin_grid_get, __aipl_concat) is written under the name it has.

The span of a node is not used: a call's span stops before its closing paren, so the source text of one is no spelling of it.
