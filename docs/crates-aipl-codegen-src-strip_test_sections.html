pub fn strip_test_sections(src: str) -> str

Returns the portion of src before the first --- name --- test-section marker line, or all of src if there is none. The cases test harness appends expected-output sections after the AIPL code with these markers; the compiler strips them so aipl run/ir/build can be pointed at a fixture directly. (parse_test_section_header classifies each line.)
