Suffix variant 

variant Suffix

One postfix step, before it has a receiver to apply to. postfix is an atom followed by a run of these, and a suffix on its own is not an expression — which is why it needs a shape of its own rather than an Expr.

A tuple index is a Field: p.0 is the field named _0, which is how the AST spells it and why nothing downstream has to know tuples have a second syntax for their fields.

One postfix step, given the receiver it applies to. A method call folds the receiver in as args[0] and flags the method form, so recv.f(a) is stored exactly as the free call f(recv, a).

fn index_or_slice(recv: Expr, index: Expr, span: Span) -> Expr

recv[a..b] — a range literal written *as* an index is the closed slice form, folded straight into a Slice rather than constructing a Span only to unpack it at runtime. A range that arrives as a *value* (recv[s], a call result) stays an index and takes the Span-index sugar path instead.
