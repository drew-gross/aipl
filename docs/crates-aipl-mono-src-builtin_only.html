The AIPL implementation of the only builtin. The loader names this function by the canonical name __builtin_only, so a user's xs.only() resolves through the ordinary generic machinery.

It is what let [x] = xs else { return none; }; asks, as an expression: let x = xs.only()?;. first is the element of an array that has one, last the element at the end, and this is the element of an array that is only that — none when there is no element, and none when there is more than one, since nothing says which was meant.
