A source file parsed and loaded as far as the loader has been ported to AIPL.

aipl_parse_file is only the parse. The loader then does more to a file than parse it, and each part of that which has moved into AIPL is a step here, so this function is what is left to burn down: a step moves in from the Rust loader, and when the last one has, the loader is this.

What has moved so far:

  • hoist_test_fns: a .test or .performance attribute becomes ordinary

top-level functions.

  • promote_type_vars: a declaration's own type parameters become type

variables.

  • lint: the lints that have been ported to AIPL. Their hits ride beside the

program, for the Rust driver to squelch and report with its own.

  • desugar: the destructuring forms are lowered. It comes after lint so the

lints read what the author wrote, with no temporaries the parser would have bound; the lints still in Rust run on what this returns.

The formatter parses with aipl_parse_file and not this, because it lays out the program the author wrote, attributes and all.
