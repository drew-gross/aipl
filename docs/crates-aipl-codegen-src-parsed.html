Stmt variant 

variant Stmt

One keyword statement, after its own production has read it and before the rest of the block is in scope. wrap_stmt is what folds it together with that rest, and several of these fold into *several* nodes — which is why a statement cannot simply lower to an Expr the way an expression does.

It mirrors gazelle's StmtSpec, which is a parser-local type there for the same reason it is one here: the AST has no statement node, so this shape exists only between the production and the fold.

  • Let(name: str, name_span: Span, ty: Ty?, value: Expr)
  • Mut(name: str, name_span: Span, ty: Ty?, value: Expr)
  • LetTuple(names: str[], value: Expr, span: Span)
  • LetStruct(struct_name: str, fields: str[], value: Expr, span: Span)
  • MutStruct(struct_name: str, fields: str[], value: Expr, span: Span)
  • Assign(lhs: Expr, value: Expr, span: Span)
  • For(name: str, name_span: Span, index: str?, iterable: Expr, body: Expr, span: Span)
  • While(cond: Expr, body: Expr, span: Span)
  • Return(value: Expr, span: Span)

ParsedBody variant 

variant ParsedBody

A parsed function body, before the return type is in scope to name the struct the shorthand constructs. Gazelle's ParsedBody, and parser-local for the same reason: by the time a Function is built the sugar is gone.

  • Block(Expr)
  • Construct(FieldInit[], Span)

ParsedParam struct 

struct ParsedParam

A parameter as written, before the destructuring form is taken apart. fields is empty for every ordinary parameter and holds the pattern's field names for Point { x, y }, whose Param is the synthetic scrutinee the function's own lowering then binds those fields off.

FnAttr struct 

struct FnAttr

One .test({ .. }) attribute: its block, and the span of the attribute name, which is where a duplicate is reported.

resolve_body fn 

pub fn resolve_body(name: str, body: ParsedBody, return_ty: Ty?) -> Expr!ParseError

The body, with the struct-literal shorthand resolved. What it builds is exactly the EConstruct the long form parses to, so nothing downstream of the parser sees the sugar at all.
