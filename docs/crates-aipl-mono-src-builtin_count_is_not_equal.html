pub fn count_is_not_equal<T: any>(self: T[], x: T, limit: u64) -> bool

Fused form of count(x) != limit — see count. Stops as soon as the count passes limit, since no later element can bring it back.

Written by the compiler's operation-fusion pass, which rewrites xs.count(x) != n (and the mirrored form) into this. Also callable directly.
