pub fn escape_text(self: str) -> str

Map a \X escape's X to its meaning: n/t/r to the control chars, and any other escaped char (", \, , {) to itself. Validity was already enforced by the matcher's scan (its escapes set), so an unknown \X never reaches here. self is the single char following the backslash.

unescape fn pub 

pub fn unescape(self: str) -> str

Decode every \X escape in self, copying everything else verbatim. Walks byte-by-byte: at each backslash (with a char after it) splice the run since the last escape plus the decoded \X, then resume past it; the trailing run is appended at the end. Copying whole runs by slicing (rather than char-by-char) keeps the common no-escape case a single copy. A trailing lone backslash can't occur — the matcher already rejected such a token as unterminated.
