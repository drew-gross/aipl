pub fn escape_text(self: char) -> str

Map a \X escape's X to its meaning: n/t/r to the control chars, and any other escaped char (", \, , {) to itself. Validity was already enforced by the matcher's scan (its escapes set), so an unknown \X never reaches here. self is the char following the backslash.

unescape fn 

pub fn unescape(self: str) -> str

Decode every \X escape in self, copying everything else verbatim. A backslash flushes the plain run before it and marks the next char as the escape's X, which is decoded on its own and starts the next run. Copying runs by slicing (rather than char-by-char) keeps the common no-escape case a single copy. A trailing lone backslash can't occur — the matcher already rejected such a token as unterminated — and would be copied verbatim if it did.
