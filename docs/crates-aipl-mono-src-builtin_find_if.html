find_if fn pub 

pub fn find_if<T: any>(self: T[], pred: (T) -> bool) -> T?

The first element of self satisfying pred, or none when none does, stopping at the first match. Generic over the element type and callable as a method: xs.find_if(pred). A str receiver iterates its chars, since str and char[] share a representation.

See any for the same scan reporting only whether a match existed, and first for the unconditional first element.
