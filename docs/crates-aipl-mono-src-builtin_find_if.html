The AIPL implementation of the find_if builtin. Monomorphization registers this function under the canonical name __builtin_find_if (see AIPL_BUILTIN_SOURCES in lib.rs), so a user's xs.find_if(pred) resolves through the ordinary generic / higher-order machinery — the in-file name find_if is only for this file's own tests, which read exactly like user code.

It is any with the element handed back: both stop at the first element satisfying pred, and where any reports only that one existed, this returns it. The optional is what carries the not-found case, so the empty array needs no special handling.

The #[allow] squelches return_loop_find_if, which flags exactly this shape — a loop returning the first match — and asks for find_if. Here it is find_if.

find_if fn 

pub fn find_if<T: any>(self: T[], pred: (T) -> bool) -> T?

The first element of self satisfying pred, or none when none does, stopping at the first match. A str receiver iterates its chars, since str and char[] share a representation.

See any for the same scan reporting only whether a match existed, and first for the unconditional first element.
