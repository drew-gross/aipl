pub fn int_parse(self: str) -> i64?

Parse self as a decimal integer: an optional leading -, then one or more ASCII digits, nothing else. none when the input is empty, a bare -, contains any other character (including +, spaces, or _), or doesn't fit an i64. The full range parses, including i64::MIN. Callable as a method: s.int_parse().
