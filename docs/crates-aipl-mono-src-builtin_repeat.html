The AIPL implementation of the repeat builtin. Monomorphization registers this function under the canonical name __builtin_repeat (see AIPL_BUILTIN_SOURCES in lib.rs), so a user's xs.repeat(n) resolves through the ordinary generic machinery — the in-file name is only for this file's own tests, which read exactly like user code.

One implementation for every sequence. A str is its char sequence, so " ".repeat(indent) is this with T = char, and [First {}].repeat(n) is this with T = First; there is no second, string-only version.

repeat fn 

pub fn repeat<T: any>(self: T[], n: u64) -> T[]

self concatenated with itself n times: [1, 2].repeat(3) is [1, 2, 1, 2, 1, 2], and "ab".repeat(2) is "abab". Empty for n == 0 or an empty receiver. The count is unsigned, matching len: a repeat count is never negative, and its usual source is length or column arithmetic (" ".repeat(indent), [x].repeat(xs.len())).

The result is sized once, up front, to exactly self.len() * n, so the copies land in one allocation with no growth in between. It is the way to build a sequence of n identical elements, in place of a loop that pushes one.
