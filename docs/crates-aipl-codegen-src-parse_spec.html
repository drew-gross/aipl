parse_spec fn 

pub fn parse_spec(src: str) -> Spec!str

Parses a case file into its Spec: the entry-point source (everything before the first --- name --- marker) plus one field per section. Section bodies have their trailing newlines stripped. Unknown section names, a malformed exit code, and an invalid companion path are errors rather than silent omissions — a mistyped marker would otherwise drop an expectation and the case would pass for the wrong reason.
