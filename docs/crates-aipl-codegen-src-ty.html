SetOrder variant 

variant SetOrder

How a set orders its elements: #{T} promises no order, #>{T} walks largest first, #<{T} smallest first. The two ordered forms require an ord element type; all three are distinct types.

show_ty fn 

pub fn show_ty(self: Ty) -> str

A type as a one-line structural dump: constructors named, leaves bare. It is the oracle the lowering's tests assert against, so it is deliberately *not* the source spelling — Array(Optional(i64)) says which way i64?[] nested, where re-rendering the source could not.

show_tys fn 

pub fn show_tys(self: Ty[]) -> str

The elements of a type list, comma-separated. An empty list renders empty, which is what () -> R and Foo<> would need if either could be written.
