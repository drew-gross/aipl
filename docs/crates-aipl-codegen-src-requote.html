requote fn 

pub fn requote(self: str) -> str

A string token's source text, respelled as whichever of the four string spellings — "…", … , """…""", … — needs the fewest escapes for its value. Ties go to a single-line form over a block (one line rather than three, or one delimiter rather than three), and then to the family the token already has (quotes or backticks), so a literal with nothing to gain is never rewritten. A value holding a newline is what the block forms are for: a block keeps its lines, and a "…"/ … with \n escapes only ever swaps between those two (reswap).

Spelling struct 

struct Spelling

One way of spelling a value, and what it costs: the escapes it needs, whether it is a block, and whether it changes the token's family (quotes to backticks or back). text is the spelling itself.

retemplate fn 

pub fn retemplate(raw: bool, segs: str[], interps: str[]) -> str

An interpolated template respelled between its two forms — …{e}… and …{e}… — by the same rule as a string: fewest escapes, then the single-backtick form, then the form it has. segs are the source texts of the template's literal segments (between the delimiters and the interpolation braces), interps the interpolations' source, which is the same in both forms and is copied through; raw says which form the source used. A template holding a newline stays as written.

The two forms share the brace escapes \{/\}; a single-backtick segment also escapes \\, \ and the control characters, which a raw segment holds verbatim — so a raw segment can become a single one when it holds no backslash (beyond a brace escape) and no backtick, and a single segment can become a raw one when its only escapes are braces, backslashes and backticks (a control-character escape has no raw spelling), which saves every backslash and backtick escape it has.

needs_escape fn 

fn needs_escape(self: char, delim: char) -> bool

Whether self must be written escaped inside a single-line literal delimited by delim: the delimiter itself, plus {/} under a backtick, where a bare brace would open an interpolation. Every other escape (\n, \t, \r, \\) is spelled the same under both delimiters.

is_shared_escape fn 

fn is_shared_escape(self: char) -> bool

Whether \X with self as X is an escape both delimiters share — so a swap copies it as-is rather than deciding it afresh for the new delimiter.

escape_cost fn 

fn escape_cost(body: str, delim: char) -> u64

How many escapes body — the source text between a literal's delimiters, escapes undecoded — would need under delim. A \X pair counts as the one char X, so \" costs one under " and nothing under a backtick, exactly as a bare " does.

redelimit fn 

fn redelimit(body: str, delim: char) -> str

body respelled for delim: an escape the old delimiter needed and this one doesn't is dropped (\" → " under a backtick), a bare char this one needs escaped gains its backslash ({ → \{), and everything else — the shared escapes, plain text — copies verbatim. Respelling for the delimiter body already has is the identity.

fn is_block(self: str) -> bool

Whether a token spells a """/ block.

reswap fn 

fn reswap(self: str) -> str

The "/ swap for a single-line literal whose value holds a newline — the one case not spelled from the value, because "a\nb" and a block are not the same number of lines and the escape is what keeps it on one. Copies the source and moves only the delimiter-specific escapes (redelimit); a tie keeps the delimiter it has.

block_ok fn 

fn block_ok(self: str, delim: char) -> bool

Whether a one-line value can be the content of a single-line block opened and closed by three delims: it must not start or end with the delimiter or contain the triple (the block's scan would close early), must not start with a space (de-denting strips it), and must hold no control character (a block has no escapes to spell one with).

better fn 

fn better(self: Spelling, other: Spelling) -> Spelling

The better of self and other: fewer escapes, then not a block, then the family the token already has — self on a tie, so the caller's order is the last word.

brace_escaped fn 

fn brace_escaped(value: str) -> str

value as the content of a raw template: verbatim but for its braces, the one escape that form decodes (unescape_braces) — a bare one would open an interpolation.

single_cost fn 

fn single_cost(value: str, delim: char) -> u64

How many escapes value needs as a single-line literal under delim: the delimiter's own (needs_escape) plus the ones every single-line form spells — a backslash, a tab, a carriage return — which a block spells with none.

encode fn 

fn encode(value: str, delim: char) -> str

value as the body of a single-line literal delimited by delim: the shared escapes for a backslash, tab and carriage return, and the delimiter's own escapes (needs_escape); everything else verbatim.

raw_seg_fits_single fn 

fn raw_seg_fits_single(self: str) -> bool

Whether a raw template segment's source can be a single-backtick segment as it is: no backtick, no control character, and no backslash but a brace escape's — anything else would need an escape the raw form never wrote.

single_seg_fits_raw fn 

fn single_seg_fits_raw(self: str) -> bool

Whether a single-backtick segment's source can be a raw segment: its only escapes are braces and backslashes, and no backslash it spells lands next to a brace — the interpolation's, at the segment's end, or an escaped one within — where the raw form would read the pair as its brace escape. A control-character escape has no raw spelling, and a backtick escape is refused too: a bare backtick next to the closing delimiter would read as part of it.

single_seg_saves fn 

fn single_seg_saves(self: str) -> bool

Whether going raw would save a single-backtick segment an escape: it spells a backslash.

single_to_raw fn 

fn single_to_raw(self: str) -> str

A single-backtick segment respelled raw: its backslash escapes become the backslash; the brace escapes stay, being the raw form's own.
