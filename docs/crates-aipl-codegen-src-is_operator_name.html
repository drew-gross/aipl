pub fn is_operator_name(self: str) -> bool

Whether self spells a built-in operator that must be imported to be used. Every operator is imported by aliasing its named builtin — equal as ==, less_than as <, wrapping_add as + — and none has a bare form. Used by the loader to gate operator imports and usage; dogfooded through the FFI.
