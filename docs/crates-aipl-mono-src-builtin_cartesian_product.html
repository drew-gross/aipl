The AIPL implementation of the cartesian_product builtin. The loader names this function by the canonical name __builtin_cartesian_product (see aipl_syntax::aipl_builtins), so a user's xs.cartesian_product(ys) resolves through the ordinary generic machinery — the in-file name is only for this file's own tests, which read exactly like user code.

A for over a call to it is fused (loop_fusions) into two nested loops, so the array below is only built where the pairs are kept. Either side may be a Span (0..3), which is taken as the array of its positions.

No lint: the shape it replaces is a pair of nested loops pushing (a, b), and there is no such site in the corpus to measure the advice against.

cartesian_product fn 

pub fn cartesian_product<T: any, U: any>(self: T[], other: U[]) -> (T, U)[]

Every pairing of an element of self with an element of other, as (from_self, from_other): all of other for the first element of self, then all of it for the next. Its length is self.len() * other.len(), and it is empty when either side is.

See zip-style pairing by position for the other way to combine two arrays; this one pairs each element with every element, not with its counterpart.
