pub fn operator_named_forms(self: str) -> str[]

The named builtins that provide the operator self — the names it is imported under (wrapping_add as +) — in the order the compiler declares them, or [] for a spelling that is not an operator. Where an operator has more than one semantics every flavor is listed, and the first is the one a diagnostic suggests first.

Mirrors OPERATOR_BUILTINS in aipl-syntax, which is where the compiler itself reads the pairing from; the two tables are kept in the same order so a diff between them reads line for line. is_operator_name is this table's question of whether the answer is empty, so the AIPL side states the pairing once.
