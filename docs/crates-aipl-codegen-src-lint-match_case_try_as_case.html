The match_case_try_as_case lint:

match (x) {
    Field(base, field) => rest,
    _ => none,
}

— as the last thing a function does: a variant value taken apart when it is one case, and given up on with none otherwise. That is let Field(base, field) = x.as_case(Field)?; followed by rest, which says the early exit first and leaves the rest of the function at one level instead of inside an arm.

It has to be the function's tail (see tail_matches): the ? returns none from the function, which is only the match's own answer when the match is what the function returns. The first arm must be a variant case's constructor pattern and the second the catch-all giving none. A first arm that returns the matched value itself, K(..) => some(x), is match_case_as_case's, whose answer is shorter still.

The hit points at the _ => none arm, a short line the formatter keeps in place, so #[allow] squelches it.
