The AIPL implementation of the internal int_parse_unsigned builtin: the unsigned half of int_parse. The loader names this function by the canonical name __builtin_int_parse_unsigned (see aipl_syntax::aipl_builtins), and loads it with any program that uses int_parse: nothing imports it, but the checker rewrites an int_parse whose position wants an unsigned integer into a call to this one, which reaches the whole u64 range where the signed parse stops at i64::MAX.

pub fn int_parse_unsigned(self: str) -> u64?

Parse self as an unsigned decimal integer: one or more ASCII digits and nothing else — no sign, not even -0. none when the input is empty, holds any other character, or exceeds u64::MAX (18446744073709551615).
