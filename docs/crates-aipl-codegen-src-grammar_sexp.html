sexp_grammar fn pub 

pub fn sexp_grammar() -> Grammar<SexpKind, Sexp>

The S-expression grammar: list -> "(" item* ")" and item -> Atom | list, with item as the start rule so a bare atom is as much a program as a list is.

item is labelled and list is transparent, so a failure inside a list reports as "an s-expression" rather than as the grammar's internals — the collapse expect_as exists for.

sexp_cst fn pub 

pub fn sexp_cst(src: str) -> Cst!ParseError

The lossless concrete tree for src — every byte of it under exactly one leaf, comments and whitespace included. Use this when the tree is the point; parse_sexp when only the Sexp is.

parse_sexp fn pub 

pub fn parse_sexp(src: str) -> Sexp!ParseError

The Sexp src denotes: lex, parse to a concrete tree, lower it through the grammar's build functions.

Fails with a ParseError carrying the span of the offending token, from either half of the front end — a lex error is reported in the same shape.

render_sexp fn pub 

pub fn render_sexp(self: Sexp) -> str

self printed back as S-expression source, in the one canonical spelling: atoms as themselves, a list as its elements joined by single spaces.

Round-trips with parse_sexp — parse_sexp(render_sexp(v)) == v for every v — which is what makes the pair a usable end-to-end check of the library.
