The AIPL implementation of the grid_of builtin. The loader names this function by the canonical name __builtin_grid_of (see aipl_syntax::aipl_builtins).

No lint: the shape this replaces is grid_from(width, (0..width * height).map(|_| value)), and a program that writes it is saying the same thing at greater length; nothing in the corpus but the program this was written for does.
