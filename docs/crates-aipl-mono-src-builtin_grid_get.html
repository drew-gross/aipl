The AIPL implementation of the grid_get builtin. The loader names this function by the canonical name __builtin_grid_get (see aipl_syntax::aipl_builtins); the parser writes grid[row, column] as a call to it.

A grid keeps its rows one after another, so the cell is row * width + column of the flat array. A column past the end of a row would land in the next row, which is why it is checked on its own; a row past the last one is already past the end of the flat array, and indexing answers none for that.
