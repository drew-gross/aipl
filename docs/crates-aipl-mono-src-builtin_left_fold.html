left_fold fn 

pub fn left_fold<T: any, A: any>(self: T[], init: A, f: (A, T) -> A) -> A

Combine the elements left to right, starting from init: for [a, b, c], f(f(f(init, a), b), c). Generic over both the element and accumulator types and callable as a method: xs.left_fold(0, |acc, x| acc + x).

Import it as plain fold — import { left_fold as fold } from builtins; — in the usual case where a file folds in only one direction; spell it left_fold only in a file that also imports right_fold, where the two need telling apart.
