map_err fn 

pub fn map_err<T: any, E: any, F: any>(self: T!E, f: (E) -> F) -> T!F

self with its error side rewritten by f: err(e) becomes err(f(e)), and ok(v) passes through untouched (f is not called). Generic over the ok type and both error types, and callable as a method: r.map_err(f).

Bridges a call whose error type differs from the enclosing function's, so ? can propagate it.
