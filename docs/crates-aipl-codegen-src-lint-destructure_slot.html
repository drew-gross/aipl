The destructure_slot lint: a name a pattern binds — the payload of a case, a position of a tuple — whose every use is a field read. The pattern can take that value apart itself, one level down:

fn f(self: Fn(function)) { function.sig .. function.body }
fn f(self: Fn(Function { sig, body })) { sig .. body }

The same argument destructure_param and destructure_binding make about a parameter and a let, one pattern further in. It applies to a pattern of either of them: a parameter's case pattern, and a let over a case or a tuple.

The slot's type is not written anywhere in the file, so the advice leaves it as a placeholder, as destructure_binding does for a let with no annotation.
