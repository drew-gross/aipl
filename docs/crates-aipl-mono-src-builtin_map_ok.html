map_ok fn 

pub fn map_ok<T: any, U: any, E: any>(self: T!E, f: (T) -> U) -> U!E

self with its value side rewritten by f: ok(v) becomes ok(f(v)), and err(e) passes through untouched (f is not called). Generic over both value types and the error type, and callable as a method: r.map_ok(f).

The mirror of map_err. Where the error is the enclosing function's anyway, f(r?) says the same thing more directly; this is for the result that is returned or stored rather than unwrapped.
