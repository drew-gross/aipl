The AIPL implementation of the pad builtin. The loader names this function by the canonical name __builtin_pad (see aipl_syntax::aipl_builtins), so a user's text.pad(10) resolves through the ordinary machinery — the in-file name is only for this file's own tests, which read exactly like user code. The file also defines Direction and its cases, which a program imports from builtins beside pad.

No lint steers the longhand here: the padding by hand is " ".repeat(width - text.len()) joined to the text in one of two orders, and which of the many ways of writing it a caller used (a loop, a map, an if on the length) is not a shape that can be advised precisely.

pad fn 

pub fn pad(self: str, width: u64, with: char = ' ', dir: Direction = Right) -> str

self made width long by adding with to the dir side of it: "ab".pad(5) is "ab ", "ab".pad(5, dir=Left) is " ab", and "7".pad(3, with='0', dir=Left) is "007". Text already width long or longer is left as it is. The length is len's, so a character wider than a byte counts as the bytes it takes. Callable as a method.
