A declaration's own type parameters, made type variables.

A type parameter is written as an ordinary identifier, so a parse leaves every mention of one as a Named type. Once the declaration is known, the mentions that are its own parameters are TypeVars: in a function's signature and annotations, in a struct's fields, in a variant's payloads, in a refinement's target. A type parameter shadows a type of the same name.

It is done to a whole Program rather than inside the parse because it needs a declaration's own parameter list, and it is done for every path alike, so no later pass has to ask whether a Named is really a variable.
