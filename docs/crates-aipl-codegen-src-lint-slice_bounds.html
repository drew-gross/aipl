What the three slice lints (slice_whole, slice_to_len, slice_from_zero) share: how to read a slice's bounds. They divide the range forms between them, so they must agree on what "runs to the end" and "starts at zero" mean.

is_len_of fn 

pub fn is_len_of(self: Expr, receiver: Expr) -> bool

Whether self is len(receiver): the receiver's own length, however it was spelled (x.len() is the free call len(x)). Spans are ignored, so the two must be the same expression, not merely equal when run.

is_zero fn 

pub fn is_zero(self: Expr) -> bool

Whether self is the number 0, written or not.

is_elided fn 

pub fn is_elided(self: Expr) -> bool

Whether self was left unwritten: the parser fills an omitted start bound with a zero that has an empty span, which is what tells x[..y] from x[0..y].
