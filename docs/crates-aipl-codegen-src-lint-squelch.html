#[allow] squelching: which lint hits an author has kept, and what is said about the rest.

AIPL has no warnings, so a lint hit is an error, but the lints (and only the lints) can be squelched by appending #[allow] to the offending line. The marker is line-scoped: it silences every hit whose span starts on its line, and nothing else. A marker on a line where no lint fires is itself an error, so a marker never outlives the code it excused.

squelch fn 

pub fn squelch(src: str, allows: Span[], hits: LintHit[]) -> LintHit[]

The hits of hits that no marker in allows squelches, each saying how to keep it, followed by an error for every marker that squelched nothing. src is the text the spans index into. A marker is not itself squelchable: what it would squelch is itself.
