Piece variant 

variant Piece

One child of a node, reduced to what layout needs from it.

Whitespace never becomes a piece: the formatter decides the spacing, so the author's is read only where it changes meaning — which is the flag on a comment, and nowhere else.

format_cst fn 

pub fn format_cst<K: variant, A: any>(g: Grammar<K, A>, src: str, node: Cst, space: (str, str) -> bool) -> Doc!ParseError

The Doc that lays node out, given the grammar it was parsed with.

space answers the one question a grammar cannot: whether a space belongs between two adjacent tokens. It is asked with the spellings on either side of the gap — space("+", "1") while laying out 1 + 1, space("(", "a") while laying out (a) — so a language brings one small function instead of a layout function per production. Where a production wants no spaces at all, that is Tight and the rule is never consulted.

Fails only on a tree that does not belong to g — a node naming a production index the grammar has no entry for, which a tree from parse_cst cannot be.

breaks_after fn 

fn breaks_after(src: str, at: u64) -> bool

Whether the source puts a line break right after position at, with only blanks in between — the end of a source line, in other words.

This tells a line comment from a block one without asking the language: a comment the author ended their line with must still end a line, or it swallows whatever the formatter puts after it. End of input counts, there being nothing left to swallow.

wrapped fn 

fn wrapped(ps: Piece[], st: ListStyle, space: (str, str) -> bool) -> Doc

Wrap: a bracketed list, on one line while it fits and otherwise one item per indented line.

The brackets are read off the tokens rather than named in the style: the leading run of matched tokens opens the list and the trailing run closes it. That is what lets one annotation cover (a, b), [a], #{a} and <T> alike, and it is also what makes an alternative with no brackets recognizable — a production whose alternatives are not all lists (AIPL's ty is one) falls back to Inline for the ones that aren't, rather than inventing break points.

list_items fn 

fn list_items(mid: Piece[], st: ListStyle, space: (str, str) -> bool) -> Doc[]

The items between a pair of brackets, each laid out inline.

A token spelled like the style's separator ends the item it follows and is dropped; the style writes the separators back, which is what lets a list that breaks gain a trailing one it never had in the source. With an empty separator every token or child starts a new item instead, which is the juxtaposed list. A comment never starts one — it belongs to the item it was written against.
