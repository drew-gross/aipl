pub fn parse_test_section_header(line: str) -> str?

If line is a --- name --- test-section marker, returns some(name) with the trimmed inner name; otherwise — or when the inner name is empty — returns none. A line is a marker iff it starts with --- with **no leading whitespace** (the marker must begin at column 0), and, once trailing whitespace is trimmed, ends with --- and is at least 6 bytes long. The cases test harness uses these markers to delimit sections; the compiler treats any such marker as a hard cutoff (see strip_test_sections).
