The formatter's raw-block re-layout: aipl-fmt's print calls this through the FFI (see install_parser_hooks) when emitting a verbatim """...""" raw string or triple-backtick template atom, to align its closing delimiter (and, for a bare-delimiter block, its content) around the column the atom opened at. base is that column (the opening line's indent) — unsigned, matching the usize the Rust caller holds, and matching the unsigned counts indent/repeat take.

pub fn reindent_block(self: str, base: u64) -> str

Re-lays-out a multi-line raw-string / template atom around base columns. The closing-delimiter line is re-indented to base — but only when it is whitespace followed by a bare triple-quote / triple-backtick delimiter (the inert blank closing line); otherwise the atom is returned unchanged. For a bare-opening block (its opening line is exactly the delimiter), the content is dedent-ed and then re-indented (via indent) so its common indent becomes base + 4 — one level deeper than the delimiters — while each line keeps its indentation relative to that common base. A content-bearing opening keeps its content byte-for-byte; only the closing delimiter moves.
