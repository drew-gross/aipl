The AIPL implementation of the is_case builtin. The loader names this function by the canonical name __builtin_is_case (see aipl_syntax::aipl_builtins), so a user's shape.is_case(Circle) resolves through the ordinary generic machinery — the in-file name is_case is only for this file's own tests, which read exactly like user code.

The shorthand for match (shape) { Circle(..) => true, _ => false }, which the match_bool_is_case lint asks for.

pub fn is_case<T: variant>(self: T, arm: Case<T>) -> bool

Whether self is the case arm, whatever its payload. arm is a constructor name, payload-carrying or not: shape.is_case(Circle).

See as_case for the value itself when it is that case, and case_of for reading which case a single value is.
