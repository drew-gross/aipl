Function struct 

struct Function

A function with nothing attached: what hoisting leaves, and every helper declared inside a block. Its .test and .benchmark attributes, as written, are an [Attributes].

shorthand_body records that body was written as the { field: value } shorthand rather than a literal naming its type; the two parse to the same Construct.

Attributes struct 

struct Attributes

What a function carries as written: its .test({ .. }) block, the functions declared inside it — helpers private to the test, never pub — and its .benchmark({ .. }) attribute. The helpers are plain Functions, so a block cannot hold another. The parser hands them over here and hoist_test_fns moves each to a top-level function under a name only the test can reach.

BenchmarkBlock struct 

struct BenchmarkBlock

One .benchmark({ .. }) attribute: its block, the functions declared inside the block (helpers private to it, as in a .test block), and the span of the attribute name, which is where a diagnostic about the attribute points.

RefinementDecl struct 

struct RefinementDecl

variant Name = V without C: a variant refined by leaving cases out, named. target is always the Without it spells. The loader substitutes it for every mention of the name and drops the declaration, so nothing past it sees one.

ConstDecl struct 

struct ConstDecl

A top-level pub let NAME: T = <literal>;. The loader substitutes each use with the literal and drops the declaration, so nothing past it sees a constant. name carries its own span, which is what the diagnostics checking a constant's two rules point at — ALL_CAPS, and a literal value.

SuperItem variant 

variant SuperItem

A top-level item, at either stage. It is used directly only by what works at both; everything else takes the refinement for its stage. The cases are named apart from every other variant's because a refinement leaves out a case by name, anywhere it can be.

SuperProgram struct 

struct SuperProgram

aipl_syntax::ast::Program, less its sources map: a single parsed file has none, and the loader fills one in when it flattens several files together.

doc is the file's own documentation — the # .. block at the top that a blank line detaches from whatever follows, so it documents no declaration. none for a file that opens with anything else, and for every program a pass builds or the loader flattens, neither of which is one file.

ParsedParam struct 

struct ParsedParam

A parameter as written, before the destructuring form is taken apart. fields is empty for every ordinary parameter and holds the pattern's field names for Point { x, y }, whose Param is the synthetic scrutinee the function's own lowering then binds those fields off. names is what each field is bound as, one per field: the field's own name, or the one written after as in Point { x as px, y }.
