lone_statement fn 

pub fn lone_statement(self: Expr) -> Expr?

The one statement a block consists of, or none when it holds anything else — no statements, or more than one. A block is a right-nested chain, and which node carries the rest of it depends on the statement: an expression statement is a Seq whose second operand is the remainder, while an assignment holds its own. Only those two forms are recognized, and each is "lone" exactly when what follows it is the block's tail.

is_lambda_safe fn 

pub fn is_lambda_safe(self: Expr) -> bool

Whether self can move into a lambda in a rewritten pipeline: a ? returns from the function it is written in, so moved into a lambda it would return from the lambda instead.

iterable_text fn 

pub fn iterable_text(self: Expr) -> str

What advice quotes for the iterable self that a loop walks: what was written where its span covers its text, and a placeholder where it does not (a call's span stops before its closing paren).

SearchLoop struct 

struct SearchLoop

A loop that returns from inside when an element passes a test:

for (let variable : iterable) { if (condition) { return returned; }; }  rest

index is the second binder of an indexed loop, and statement is the return. What the loop returns and what it falls through to are the lint's to read.

search_loops fn 

pub fn search_loops(self: Expr) -> SearchLoop[]

Every [SearchLoop] in self and under it. A for is a statement of a block, so it is the first operand of a Seq whose second is what the loop falls through to. The body is an else-less if around a lone return: an else, or a second statement, is work a searching builtin has nowhere to put.

answers_none fn 

pub fn answers_none(self: Expr) -> bool

Whether self — what a loop falls through to — is the not-found answer: a bare none as the block's tail, or an explicit return none;. Anything else, and the fall-through does work a searching builtin would skip.

is_block_tail fn 

fn is_block_tail(self: Expr) -> bool

Whether self is what the parser ends a statement-only block with: () for an ordinary block, and an 0 with no location of its own — the loop expression's result — for a loop body, which may not end in a value of its own at all. The loop's zero is told from a written one by its empty span, the way slice_from_zero tells an elided slice bound from a typed one.
