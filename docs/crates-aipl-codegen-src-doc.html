Doc variant 

variant Doc

A layout tree: the layouts a printer may choose from, with the width limit deciding which. Each Group renders flat when it fits and breaks otherwise, and every other case says what it contributes in each of those two states.

  • Text(str)

    A verbatim literal. A multi-line one forces a break.

  • Concat(Doc[])

    A sequence, laid out in order.

  • Line

    A space when flat, a newline when broken.

  • SoftLine

    Nothing when flat, a newline when broken.

  • HardLine

    Always a newline.

  • BlankLine

    Always a blank line.

  • Indent(Doc)

    One indentation level deeper.

  • Group(bool, Doc)

    Flat if it fits; the flag says it never can (see group).

  • IfBroken(str)

    Text that appears only when the enclosing group breaks.

  • BreakParent

    A zero-width forced break.

  • RawBlock(str)

    A verbatim multi-line atom, re-aligned around its column by reindent_block.

group fn 

pub fn group(self: Doc) -> Doc

Wrap self in a group, pre-computing whether it is forced to break. Forcing is what makes a multi-statement block, or any construct holding a line comment, lay out vertically no matter the width.

print fn 

pub fn print(self: Doc, width: u64) -> str

Render the document at the given width limit. Lines are indented with spaces; trailing whitespace is stripped from every line, and the result ends in a newline whenever it spans more than one line.

has_hard fn 

fn has_hard(self: Doc) -> bool

Whether self contains content that can never render flat: a hard/blank line, a break-parent, or multi-line verbatim text. Recurses through nested groups — a forced inner group means the outer can't be flat either.

go fn 

fn go(width: u64, col0: u64, work0: Work, acc0: str[]) -> str[]

The main layout loop: pop a frame, emit for its Doc, push any children, and go round again. col is the current column; sp (inside each frame) is the indentation, in spaces, that a line break under that frame lands at.

Each arm updates the loop's own mut bindings directly. That needs match arms to be statement blocks; before they were, an arm could only be a single *expression*, so this was three functions threading a Step { col, work, emit, emits, done } carrier back to the loop — one to dispatch on the work-list, one on the Doc, and one for the RawBlock atom.

group_flat fn 

fn group_flat(forced: bool, width: u64, col: u64, sp: u64, inner: Doc, rest: Work) -> bool

Decide a group's mode: forced groups always break; otherwise the group is flat exactly when its content — laid out flat, followed by the rest of the line — fits in the remaining width. The remaining width is an *unsigned* subtraction, so a line already past the limit floors at 0 rather than going negative — the same thing the Rust printer gets from usize::saturating_sub.

fits fn 

fn fits(budget: u64, work: Work) -> bool

Would the pending work — the flat candidate followed by the outer frames, each in its own mode — stay within budget columns? Walks until the budget is exhausted (no) or the line provably ends at a break point (yes).

The budget is *unsigned*: it can't go negative, so an overrun is an explicit "doesn't fit" comparison in fits_after rather than a sign check on a wrapped-around remainder.

fits_after fn 

fn fits_after(budget: u64, n: u64, rest: Work) -> bool

Spend n of the remaining columns and keep walking — or give up when n doesn't fit. The check has to come *before* the subtraction: on an unsigned budget budget - n floors at 0, which would hide the overrun.

fits_atom fn 

fn fits_atom(budget: u64, s: str, flat: bool, rest: Work) -> bool

A Text/RawBlock atom in fits: a multi-line atom can't sit on a flat line (so it only "fits" when the surrounding content is already broken); a single-line atom just consumes its width.

prepend fn 

fn prepend(ds: Doc[], sp: u64, flat: bool, rest: Work) -> Work

Prepend an array of children onto the work-list so ds[0] is processed first: a right fold over ds, each frame carrying the parent's indent and mode.

col_after fn 

fn col_after(col: u64, text: str) -> u64

The column just past text when appended at column col: the length of its last line for multi-line text, else col + width.

newline_str fn 

fn newline_str(sp: u64) -> str

A line break landing at indentation sp: a newline plus sp spaces.

blank_str fn 

fn blank_str(sp: u64) -> str

A blank-line break at indentation sp: two newlines plus sp spaces (the blank line's own trailing spaces are removed by cleanup).

cleanup fn 

fn cleanup(out: str) -> str

Strip trailing whitespace from every line, and end a multi-line result with a newline — a single line is a fragment, anything longer is a block. The whole text is trimmed first so a break the layout left dangling at the end (a newline plus its indentation) does not become a trailing blank line.
