Arrays: a growable, refcounted sequence of primitives written T[] (e.g. i64[], char[], bool[]).

  • [a, b, c] constructs an array literal ([] is the empty one)
  • xs[i] indexes, yielding T? — some(elem) in bounds, none when i is out of range
  • len(xs) returns the element count
  • xs.push(x) appends x to the array variable xs in place (xs must be mut); copies of xs are unaffected
  • [..xs, y] splices xs's elements into a new literal, so this is xs with y appended; xs itself is untouched
  • for (let x : xs) { ... } iterates the elements in order
